# Amber Rewards: Shopping Bag prototype

Interactive prototypes of the Amber Rewards section in the Shopping Bag, shown side by side for three scenarios: signed in and linked, signed in but not linked, and guest.

In the signed-in, not-linked scenario, the closed card offers a Link Account action that opens the linking modal at the code step and then the redeem modal.

Open `index.html` in a browser, or view it on GitHub Pages.
